AI Job Market Finder

Python · Shiny for Python · Plotly, plotnine, WordCloud
Python Shiny Plotly Interactive Dashboard

Overview

An interactive web app built with Shiny for Python that lets users explore a Kaggle AI job market dataset — filtering by job title, experience level, company, and required skills, then browsing salary trends, job demand, and skills analysis through linked, reactive visualizations. All charts update live as filters change, so a user can go from "AI jobs in general" to "Senior ML Engineer roles requiring PyTorch" in a few clicks.

What it does

Salary & Experience

Average salary trend by experience level, salary comparison by job title and experience (grouped bar), job count by experience level, and a full min/avg/max salary range breakdown.

Job Demand

A bar chart of job title demand across the filtered dataset, showing which roles appear most frequently in current postings.

Skills Analysis

A word cloud generated live from the "skills required" field across all filtered postings, sized by frequency — a fast way to see which skills dominate a given slice of the market.

Job Explorer

A searchable, filterable data table of the underlying postings, so a user can drop from the charts straight into the raw rows behind them.

How it's built

The app parses a min–max salary range field into numeric min, max, and average columns on load, then builds four selectize filters (job title, experience level, company, skills) that all feed a single reactive df_filtered() calculation. Every chart reads from that one filtered dataframe, so the whole dashboard stays in sync no matter which filter changes.

Charts are split across three libraries depending on the job: Plotly for the interactive salary and demand charts (hover, zoom), plotnine for a clean ggplot-style bar chart of job title demand, and matplotlib/WordCloud for the skills visualization. Empty-state handling was built in for every chart, so an over-filtered view shows a clear "no data" message instead of a broken plot.

# Reactive core — every chart reads from this one filtered frame
@reactive.calc
def df_filtered():
    sel_job = input.job()
    sel_experience = input.experience()
    sel_company = input.company()
    sel_skill = input.skill()

    filtered_df = df.copy()
    if sel_job:
        filtered_df = filtered_df[filtered_df["job_title"].isin(sel_job)]
    if sel_experience:
        filtered_df = filtered_df[filtered_df["experience_level"].isin(sel_experience)]
    if sel_company:
        filtered_df = filtered_df[filtered_df["company_name"].isin(sel_company)]
    if sel_skill:
        filtered_df = filtered_df[filtered_df["skills_required"].isin(sel_skill)]
    return filtered_df

The app also includes a dark-mode toggle (ui.input_dark_mode()) and a tabbed layout (navset_tab / navset_card_tab) so the three analysis areas — salary, demand, skills — stay organized rather than stacked on one long page.

Stack

  • Shiny for Python (Express UI) for the reactive app framework
  • Plotly via shinywidgets for interactive charts
  • plotnine for a ggplot2-style static bar chart
  • WordCloud + matplotlib for the skills word cloud
  • pandas for all data wrangling and the reactive filter pipeline
